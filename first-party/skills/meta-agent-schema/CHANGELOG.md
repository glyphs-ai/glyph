# Changelog

## 0.2.0 (2026-07-07)

- Add the optional `type` field to the skill frontmatter schema. Currently recognized value: `strategy` (a skill loaded by a coord-shaped agent alongside `official/workflow-coordination`; formally invokes the naming exception that lets strategy case-banks + dispatch templates name the loading coord agent + worker agent FQNs). Unknown values are accepted but carry no semantics.

## 0.1.1 (2026-07-07)

- Trim the "single source of truth" / "this skill is the bug" meta-prose in the lead and References sections.
- Point at the `@glyphs-ai/catalog` package by name for the runtime validators (was `packages/catalog/src` internal path).

## 0.1.0 (2026-06-11)

- Initial release.
